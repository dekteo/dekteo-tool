# Следующая основа Dekteo — решение по результатам прототипа

23.09.2026. Это проектирование и эксперимент, не объявление о полном переносе.

## Цель
Живой PNG-персонаж без камеры, доступный новичку. Сложность раскрывается постепенно.
Рабочая WPF-версия сохраняется. Её копия — `artifacts/baseline-2026-09-23`;
профили и PNG остаются на прежних местах и не читаются новым прототипом.

## Предлагаемая структура
- Проект: версия формата, холст, ресурсы, персонажи, вывод.
- Слой: стабильный ID, имя, parentId, порядок отображения, локальные положение/масштаб/поворот/pivot,
  видимость и блокировка, изображение, необязательная карта нормалей/маска, поведения.
- Группа наследует движение, но порядок отрисовки задаётся отдельно от связи с родителем.
- Рот — один слой с набором изображений; звук выбирает форму, громкость — открытие.
  Пустые комбинации используют заданный fallback. Не заставлять загружать все сочетания.
- Поведения: дыхание, взгляд, моргание, речь, запаздывание деталей; каждое отключается отдельно.
- Перед перепривязкой проверять циклы. При смене родителя предлагать сохранение мирового положения.
- Ресурсы PNG не переписываются; сохранение проекта атомарное, формат версионирован.

## Интерфейс
Простой вид: изображения, микрофон, моргание, OBS, проверка без голоса.
Живой вид: дополнительные готовые настройки взгляда, дыхания и головы.
Редактор: дерево слева, сцена в центре, свойства выбранной части справа.
Переключение вида только меняет доступность панелей, не удаляет конфигурацию.
Инструменты сцены: перемещение/размер/pivot, отмена/повтор, выбор перекрытых слоёв.
Просвечивание чужих слоёв применяется только в редакторе, не в трансляции.
Свет и вывод — свойства сцены, а не случайного выбранного слоя. В прототипе свет пока
размещён в правой панели рядом с инспектором для быстрой проверки.

## Технологический эксперимент
`prototypes/godot-layers` — Godot 4.7.2 standard, GDScript, Compatibility/OpenGL.
GDScript выбран для маленького изолированного теста. Это не решение переписать существующий
анализатор речи: для продукта отдельно оценить Godot .NET и перенос независимых C# сервисов.
WPF контролы напрямую не переносятся. Формат профиля потребуется мигрировать с копией исходника.

Что сейчас проверяет прототип:
- Sprite2D с CanvasTexture (цвет + normal), PointLight2D;
- наследование трансформаций body → head → eyes/mouth;
- постоянно обновляемый SubViewport; редактор и окно вывода используют одну текстуру;
- ручной выбор входа и локальный AudioEffectCapture; синтетический тест рта;
- импорт PNG и карты нормалей с проверкой совпадения размеров.

Следующий этап 23.09: реализованы переносимый архив `.dekteo` (JSON v1 + PNG/normal),
добавление/удаление/названия/видимость/порядок, привязки с сохранением мирового transform,
перетаскивание, масштаб/поворот, история 64 действий и предупреждение о несохранённых правках.
Схема первого формата: `prototypes/godot-layers/layer_project.gd`.

Не реализовано: полный редактор слоёв, фонемы, перенос профилей, сеточная деформация,
руки/устройства, камера, импорт чужих форматов. Не выдавать макет за новую готовую версию.

## Критерии решения
1. На реальной модели слои, маски и шея совмещаются без потери качества.
2. При свёрнутом редакторе отдельный вывод продолжает обновляться.
3. OBS действительно захватывает нужную прозрачность; проверить на устройстве, не по свойству окна.
4. Микрофон не даёт слышимого мониторинга; реакция/задержка не хуже текущего приложения.
5. CPU/GPU и кадровые пики измерены на одинаковой сцене, включая сложную модель.
6. Есть протестированная миграция копии старого профиля с сохранением калибровки.

До прохождения критериев: Godot — перспективный кандидат, окончательный переход не утверждён.
Следующий этап после проверки вывода/аудио — минимальный сохраняемый формат слоёв,
импорт копии персонажа и Undo/Redo, затем новый интерфейс поверх этого формата.
